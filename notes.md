### Problem

"Patient data lives in independent, incompatible systems with no shared record, so specialists work with dangerous blind spots. Our MCP server exposes each system through one uniform interface, and the assistant assembles a single Clinical Snapshot — surfacing cross-source conflicts, like an allergy in one system that contradicts a prescription in another, that no individual department can see. We assume patient identity is already resolved; matching is a known, separate problem."
